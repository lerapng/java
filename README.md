Лекція 9. Можливості Java від switch до обробки подій у Swing

Код розбитий по відповідних пакетах у `src/main/java/`:

* `l01_switch` — оновлений синтаксис `switch`, стрілочки `->`, списки констант у `case`, вирази з `yield`. Також тут є реалізація завдання з розподілом студентів по факультетах (`StudentFacultyDemo.java`).
* `l02_records` — приклади використання `record`, компактні та неканонічні конструктори, перевірка даних і власні методи.
* `l03_sealed` — запечатані класи (`sealed class`) та інтерфейси (`sealed interface`), обмеження ієрархії наслідування.
* `l04_pattern_matching` — сопоставлення з шаблоном для `instanceof` та перевірка типів у `switch`.
* `l05_swing` — приклади GUI на Swing: базові компоненти, контейнери (`JFrame`, `JPanel`), компоновка (`BorderLayout`) та обробка подій через слухачі та лямбда-вирази.
